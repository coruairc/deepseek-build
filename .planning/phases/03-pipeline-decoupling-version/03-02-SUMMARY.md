## Decisions Made

- **Only the four `0.0.1-rc5` crates inherit.** The 83 literal `version = "0.1.0"` manifests and the unrelated odd-versioned crates stay literal, as the plan requires; no manifest outside the four was opened.
- **The test targets `xai-grok-pager-bin`,** because the human-visible `--version` string is `env!("VERSION_WITH_COMMIT")` from pager-bin's `build.rs`, not `xai-grok-version::VERSION`. Pinning the manifest value in the crate whose manifest drives the output is what makes the test meaningful.
- **The expectation is read at runtime** (`std::env::var("GROK_VERSION").unwrap_or("0.1.0")`), so the test process and the compiled binary agree by construction about which path is under test.
- **The commit token accepts 7–40 hex characters,** matching the CI needle in `release.yml` rather than hardcoding 12, so the assertion stays valid if the truncation length ever changes.
