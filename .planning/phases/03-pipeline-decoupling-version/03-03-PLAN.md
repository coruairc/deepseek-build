budget: `release-dist` must emit no DWARF, the macOS binary must carry a signature that survives stripping
and packaging, and the check must run on the extracted tarball rather than on the pre-tar build output
(REL-07, REL-03, with REL-02's budget work prepared but left for Phase 4 to prove).

DWARF (module-level, more than line tables), and the smoke check runs `target/release-dist/deepseek-build`
before packaging — which proves nothing about what a user downloads. The 90-minute macOS budget already
failed once (`v0.0.1-rc4`, run `40111152104`).

verification step that asserts the signature, the version and the absence of `__DWARF`/`.dSYM`, a 240-minute
