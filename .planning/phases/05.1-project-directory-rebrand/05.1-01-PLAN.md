## Objective
Add `PROJECT_DIR_NAME` / `LEGACY_PROJECT_DIR_NAMES` to `xai-grok-brand` and make every
project-scoped resolution use them, preferring `.deepseek` and falling back to `.grok`.

## must_haves
- `xai-grok-brand::PROJECT_DIR_NAME == ".deepseek"` and `LEGACY_PROJECT_DIR_NAMES == [".grok"]`.
- No production code hardcodes a project-scoped `.grok` path: every site resolves through the constant.
- A repo with only `.grok/agents`, only `.grok/skills`, or only `.grok/config.toml` still works (dedicated tests).
- With both present, `.deepseek` wins (dedicated precedence tests per surface).
- The home dir, `~/.grok` legacy reads, session storage and `.grok-snapshots` are unchanged.
