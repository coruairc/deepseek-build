## Trust Boundaries

| Boundary | Description |

| gate -> human judgement | a green gate is taken as proof the suite ran; the gate must not be able to skip silently |
| test evidence -> committed repository | captured terminal output can carry secrets, absolute paths and hostnames |
| evidence helper -> report.json | the report is the artifact a reviewer trusts instead of re-running |
