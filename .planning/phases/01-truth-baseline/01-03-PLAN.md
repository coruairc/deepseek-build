| Boundary | Description |
|----------|-------------|
| config file -> status line / headless | `[ui]` is user-controlled input parsed at startup; a malformed table must fall back, never fail the run |
| pricing table -> user-facing number | a mispriced table silently misstates spend; no user can detect it |
| headless JSON -> downstream consumer | a consumer sums `estimated_cost_usd` and must be able to trust the `estimate: true` marker beside it |
