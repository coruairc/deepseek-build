<objective>
Turn the egress measurement that `scripts/egress-check.sh` already printed during the PROOF-01 session into a
committed, re-runnable `runtime-egress` item — same session, read back from its committed transcript, with no
second live run and no new harness.

Purpose: PROOF-02 says the egress boundary is measured "on that same session". The measuring tool ran in that
session and printed its own destination table and verdict; what is missing is a committed artifact that makes
the reading checkable by someone who was not there. A second live run would weaken the claim, so this plan
reads the recording instead.

Output: the `runtime-egress` item — a fixed-schema report, a small re-runnable checker, the parsed destination
table, and notes that state the measurement's blind spots.

Execution shape: no toolchain, no key and no network are needed. `python3`, `git` and `grep` are enough, so this
plan can run on any host once 02-01 is merged. It is `autonomous: true` for that reason.
</objective>
