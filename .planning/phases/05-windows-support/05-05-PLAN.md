## Objective
Produce and accept a real Windows artifact: run the release workflow with the Windows leg,
download the zip, run `install.ps1` (and `scripts/test-install.ps1`) on Windows, drive the TUI
under ConPTY for a shell command and a file edit, and record what did not run.
## must_haves
- The zip exists on a release, contains the five top-level files, and its `--version` prints the tag.
- `install.ps1` installs and uninstalls from the real release; the harness passes on Windows.
- The ConPTY check is recorded (or explicitly not run, with the reason).
- The record lists the unix-gated tests that do not run on Windows.
