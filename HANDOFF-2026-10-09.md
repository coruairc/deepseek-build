- **Toolchain** Rust 1.94.0 pinned; `protoc` on PATH; `strace` is **absent** on the
  original host (use `scripts/egress-check.sh`, an LD_PRELOAD logger).
- **Config dir** `~/.deepseek-build`; **env** `DEEPSEEK_API_KEY` (primary) /
  `DEEPSEEK_BUILD_API_KEY` (fallback); API-key auth only (env-only).
- **Default model** `deepseek-v4-pro` (`deepseek-flash` is the cheap tier; hidden
  `deepseek-v4-flash` alias). Provider = OpenAI-compatible Chat Completions at
  `https://api.deepseek.com`; custom `base_url` supported.
- **Default sandbox profile is `off`.** Opt-in profiles (`strict`, `workspace`,
  `devbox`) **fail closed**: if `bwrap` is missing/broken they refuse to start
  with: `error: this sandbox could not enforce its deny list on Linux: bwrap exec
  failed: … Refusing to start with denied paths unprotected.` The main sandbox is
  Landlock/seccomp; bwrap only backs the deny-list mounts.
- **Cost** is a local peak-rate estimate from the shipped DeepSeek table
  (D14); the provider reports no price.
- **`main` is a strict ancestor of `dsb/integration`** — fast-forward to update
  `main` after pushing the integration branch.
